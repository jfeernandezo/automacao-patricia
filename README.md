# Apresentacao: DM automatico sem ManyChat

Pagina unica, sem build e sem dependencia externa, publicada via GitHub Pages.

Compara o funcionamento do DM automatico do Instagram no ManyChat e numa
estrutura propria com n8n: fluxos desenhados, variacoes de caminho, sequencia
de mensagens e painel de cliques nos links.

- `index.html` — a apresentacao inteira (HTML + CSS + SVG num arquivo so)

A pagina traz `<meta name="robots" content="noindex">` de proposito: o link
funciona para quem recebe, mas nao entra em buscador.

Para publicar: Settings -> Pages -> Source: `main` / `/ (root)`.
